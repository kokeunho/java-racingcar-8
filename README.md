# java-racingcar-precourse

1. 입력 검증
    - 자동차 이름 입력<br>
        차량 수가 2대 이상일 것<br>
        자동차 이름 글자 수가 1~5 글자일 것
    - 실행 횟수 입력<br>
        1 이상의 값일 것

   
2. 게임 진행
    - 게임 세팅<br>
        쉼표(,)로 입력 구분하여 Car 객체 생성 
    - 라운드 별 차량 동작<br>
        각 차량 별 Randoms.pickNumberInRange(0, 9)의 값이 4 이상이면 전진 
    - 라운드 별 이동 현황 출력
    - 우승자 반환
        우승자 리스트 반환


3. 우승자 출력
    - 우승자는 쉼표(,)로 구분하여 출력
